# Вбудовані асети (source-embedded assets)

Усі зображення сайту — постери, ілюстрації статей, банер 4:1, прев’ю ресурсів,
фото та фон автора, а також **згенеровані GIF-анімації** зі статичними кадрами —
зберігаються в цій теці як звичайні текстові TypeScript-модулі з base64 data URI.

Це означає, що асети **імпортуються разом із кодом** і завжди потрапляють до
завантаженого архіву проєкту. Сайт не залежить від зовнішніх URL і не потребує
бінарних файлів у `public/images` для відображення картинок.

| Модуль | Вміст | Де використовується |
| --- | --- | --- |
| `posters.ts` | 4 постери статей | головна, блог, картки статей |
| `articleImages.ts` | 9 ілюстрацій + банер | сторінки статей |
| `gifs.ts` | 4 анімовані GIF + 4 статичні кадри | шапки калькуляторів |
| `resourcePreviews.ts` | 5 прев’ю ресурсів | сторінка «Корисні ресурси» |
| `authorImages.ts` | фото інкогніто та фон | сторінка «Автор» |

## Команди

```bash
# Перегенерувати TS-модулі з бінарних файлів public/images
node scripts/generate-asset-modules.cjs

# Відновити бінарні файли public/images із TS-модулів (після скачування проєкту)
node scripts/restore-assets.cjs

# Перегенерувати самі SVG-анімації (GIF) з нуля
node scripts/generate-gifs.cjs
```

`scripts/asset-map.cjs` — єдина карта відповідності між ключами модулів і файлами.

GIF-анімації створюються з векторних SVG-кадрів скриптом `scripts/generate-gifs.cjs`.
Для користувачів із `prefers-reduced-motion: reduce` замість GIF показується
статичний кадр (`still`).
